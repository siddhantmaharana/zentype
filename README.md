# zentype

A minimal typing app — drop a `.txt` or `.md` file and just type.

## Usage

1. Open `index.html` in your browser (Chrome/Firefox)
2. Drag & drop any `.txt` or `.md` file onto the window
3. Start typing — that's it

Markdown formatting is stripped so you just see the plain text to type through.

## Run as desktop app

```bash
pip install pywebview
python3 main.py
```
